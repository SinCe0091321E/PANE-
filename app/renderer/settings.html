适配器接口

每个站点由一个 *.adapter.js 描述：mode 决定布局（translate / gallery / generic）， selectors 决定识别哪些元素，hide 与 css 决定站点被裁成什么样， tools 决定左侧出现哪些工具。改完重启 PANE 即可生效。 

module.exports = {
  id: 'my-site',
  name: '我的站点',
  mode: 'gallery',           // translate | gallery | generic
  match: ['*://example.com/*'],
  tools: ['search', 'zoom'],
  search: { url: 'https://example.com/search?q={query}' },
  hide: ['.header', '.footer'],
  selectors: { galleryItem: ['img'] },
  css: `img { border-radius: 10px }`
};
