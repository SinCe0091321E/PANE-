把常用网站挂在桌面上的极简浮窗

---

PANE（浮窗 FloatDock）是一个 Windows 桌面浮窗工具：无边框、可拖动缩放、能固定在桌面最上层，也能一键缩进系统托盘。

它不只是“把网页塞进小窗口”——针对翻译、图片、文章、视频、音频分别做了适配，让常用网站更接近一个原生小工具。

- **绿色免安装**：解压即用，不改注册表，不需要管理员权限
- **六种站点类型**：翻译 / 图片 / 文本 / 视频 / 音频 / 通用
- **本地优先**：没有账号体系、没有云端同步，所有数据都在程序目录的 `data/`
- **零前端框架**：原生 HTML / CSS / JS，打包器只依赖 Node 标准库

> 当前版本：**PANE 1.0** · Windows 10 / 11 x64

## 功能

### 翻译

- **直接使用网站原页**（如百度翻译），输入后由网站自己翻译，延迟与原站一致
- 语言选择、语言互换、复制译文、自动翻译、站内缓存均由网站原生提供
- 左侧工具保留：
  - **朗读原文 / 朗读译文**（系统语音，切换时自动停掉上一个）
  - **拼音 / 音标**弹层：中文拼音、英文 IPA（联网查询并缓存）
  - 聚焦裁剪、缩放、在浏览器打开

### 图片

- 页面按窗口宽度自适应，不再整页左右滑动
- 横向图片栏目：鼠标放上去用**滚轮横向滚动**
- **左键**图片：窗口内全屏预览（滚轮缩放、拖动平移、Esc 关闭）
- **右键**图片：窗口内查看 / 系统全屏 / 保存图片 / 复制图片地址

### 文本（阅读器）

- 默认停留在网站原页，搜索、翻页正常；点「阅读模式」才进入阅读器
- 自动提取标题、段落、小标题、列表、引用、代码和图片
- 正文限宽 720px、1.9 倍行高；顶部进度条可拖动定位
- 字号 A− / A+
- **临时标注**：黄 / 绿 / 粉，点已有标注可取消；「去标」「清除」
- **目录**、**下载为 .txt**、随时切回「原页」
- 标注只在本次页面有效，不改动网站

### 视频 / 音频

- 底部自有控制条，保留原网站画面
- **进度条可点击、可拖动**，拖动时边拖边跳，松手精确落位
- 音量 / 静音、0.5×–2× 倍速
- **时间点标记**：记录、跳转、删除，进度条显示小旗点
- 音频可「提取音频」进入纯音频面板，支持前后 10 秒
- 标记只在本次页面有效

### 本地导入

- 左侧「导入本地」支持 **图片 / 文本 / 视频 / 音频**
- **重新导入会先关闭上一个本地文件**，视频/音频不会留在后台播放
- 断网时，离线卡片上也会出现四个本地入口
- 本地文件通过本机读取/播放，不经过网络

### 多窗口与托盘

- 左侧「新建窗口」可再开独立浮窗（最多 8 个），各自选站点、各自操作
- 独立窗口的 × 只关闭它自己；主窗口的 × 退出整个程序并关闭所有窗口
- 「收到后台」隐藏到系统托盘：左键恢复，右键弹出带图标的「打开 / 设置 / 退出」
- 找不到窗口时按 **Alt + Shift + F**

### 外观

- 浅色 / 深色 / 灰色 / 纸张黄 / 跟随系统
- 强调色、窗口圆角、正文字号、动效档位
- **毛玻璃材质**：Windows 11 亚克力（系统不支持时可能无效果）
- 深色下可让文字型网站一起压暗
- 自动朗读译文、左键托盘打开等开关

### 离线

- 断网时使用应用内提示，而不是浏览器错误页
- 恢复联网后自动重载当前站点
- 翻译站点同样显示离线提示
- 离线时可直接导入本地图片 / 文本 / 视频 / 音频

## 快速开始

1. 前往 [Releases](../../releases) 下载 **`PANE-1.0.zip`**
2. **完整解压**到任意文件夹（不要在压缩包预览里直接运行）
3. 双击 **`启动浮窗.vbs`**
4. 如果 Windows 提示 SmartScreen：点 **「更多信息 → 仍要运行」**

首次启动会在程序目录生成 `data/`，用于保存配置、缓存和登录状态。

想放到桌面：右键 `创建桌面快捷方式.ps1` → 使用 PowerShell 运行。

详细说明见 **[PANE-1.0-使用介绍.md](PANE-1.0-使用介绍.md)**。

### 站点类型

| 类型 | 适合的站点 | 主要能力 |
| --- | --- | --- |
| 翻译 | 百度翻译等 | 网站原页 + 朗读、拼音/音标、裁剪、缩放 |

## 从源码构建

需要 Node.js（仅用于打包，项目本身没有 npm 依赖）。

> 仓库不包含 `runtime/`。自行构建请准备兼容的 Electron 44 运行时，放到 `runtime/`，主程序命名为 `FloatingDock.exe`；或者直接下载 Release 中的绿色包。

```bash
# 打包 app/ → runtime/resources/app.asar + app-files
node tools/build.js

# 启动
powershell -ExecutionPolicy Bypass -File tools/launch.ps1
```

也可以直接双击 `启动浮窗.vbs`。

## 目录结构

```
app/                 Electron 主进程、preload、渲染页面、adapter
  adapters/          站点适配器（翻译/图片/文本/视频/音频/通用）
  main/              窗口、托盘、设置、存储、翻译与本地文件
  preload/           shell / content / tray 三套 preload
  renderer/          无框架的 HTML / CSS / JS 界面
tools/               asar 打包、启动、截图、CDP 调试脚本
启动浮窗.vbs         启动入口
PANE-1.0-使用介绍.md 用户使用说明
```

`runtime/`、`data/`、`launch.log` 不进入仓库（见 `.gitignore`）。

## 设计原则

- **不改网站**：标注、视频/音频标记只在本次会话里，不写入网站
- **本地优先**：没有账号、没有云端同步，数据都在 `data/`
- **适配器驱动**：站点差异放在 `app/adapters/*.adapter.js`，可用元素拾取与自定义 CSS/JS 扩展
- **零前端框架**：原生 HTML/CSS/JS，打包器只依赖 Node 标准库
- **会话级数据**：标注、标记、本地导入不落盘，关闭即清空

---

## 数据与隐私

- 所有配置、缓存、Cookie 都在程序目录的 `data/`
- 恢复默认：退出软件 → 删除 `data/` → 重新启动
- 卸载：退出软件 → 删除整个程序文件夹
- 没有遥测、没有账号、没有云端上传
- 本地导入的文件不会上传

---

## 已知限制

- 仅支持 Windows 10 / 11 x64
- 毛玻璃材质需要 Windows 11；系统不支持时可能没有模糊效果
- 部分网站禁止被嵌入，可用「在浏览器打开」
- 网站改版可能导致适配器失效，可用元素拾取重新绑定
- 程序未签名，首次运行可能出现 SmartScreen 提示
- 翻译、音标、在线视频/音频需要联网

## 常见问题

**托盘图标找不到？**
Windows 11 默认把新图标放进隐藏区：设置 → 个性化 → 任务栏 → 其他系统托盘图标 → 打开「浮窗」。也可以按 `Alt + Shift + F` 找回窗口。

**网站打开是空白？**
部分网站禁止被嵌入，或页面结构变化。先在浏览器打开对比；再到设置里检查适配器/元素绑定。

**标注或标记不见了？**
它们是会话级的，刷新、切换站点或关闭后会自动消失，这是刻意设计。

**为什么翻译不再有独立面板？**
1.0 起翻译直接使用网站原页，速度与原站一致；朗读、拼音/音标等工具保留在左侧。
